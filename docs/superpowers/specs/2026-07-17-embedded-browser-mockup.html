五、iframe 被拒绝嵌入 兜底

GitHub / Google 等站点通过 X-Frame-Options / CSP 拒绝被 iframe，会显示空白。按设计：不做自动检测，「在浏览器打开」按钮始终常驻。用户发现打不开时，直接点按钮转默认浏览器。
